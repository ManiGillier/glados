7.4.3 Portability Issues ¶

Platform Word Size - ‘PC’ and ‘SP’ use Haskell ‘Int’ type - 32-bit systems: Max ~2GB bytecode - 64-bit systems: Max ~8GB bytecode - Not a practical concern for typical use
