# Security feature list, every situation where the program will return an error :
## The errors of the main function :
- compilation attempt without main function
- compilation attempt with several main function

## The fuction's errors
- Attempt to creaye an already existing function
- Call to a no existing function
- Call to a function with an incorrect amount of arguments
- Attempt to return a value in a void defined function.

## Les erreurs de variable :
- Attempt to create an already existing variable
- Call to a non existing variable
