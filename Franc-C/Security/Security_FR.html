Liste des fonctionnalités de sécurité, les situations dans lesquels le programme renverras une erreur :

Les erreurs de la fonction principale :

  • Tentative de compilation sans fonction principale manquante
  • Tentative de compilation avec plusieurs fonctions principale

Les erreurs de fonction

  • Tentative de création d'une fonction déjà existante
  • Appel à une fonction innéxistante
  • Appel d'une fonction avec un nombre incorrecte de paramètres
  • Tentative de renvois d'une valeur dans une fonction définie comme nulle

Les erreurs de variable :

  • Tentative de création d'une variable déjà existante
  • Appel à une variable innéxistante
