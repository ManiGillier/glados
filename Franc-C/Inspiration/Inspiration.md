# Inspirations
## Technical inspiration
> This language is heavily inspired by the C programming language. It uses the same algorithmic logic, allowing a wide application in system programming, or software development.
## Typographic inspiration
> The Franc-C, while using the algorithmic logic of the C programming language. It was designed to be accessible to any french speaking person no matter their knowledge in programmation, this is why we are following the french languages syntaxic rules.
