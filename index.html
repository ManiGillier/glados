Franc-C

The Franc-C is a language created to complete the project GLaDOS from the school Epitech.

We take inspiration from the programming language : C for the logic and the French language for the syntax.

The project was realised in Haskell.

Getting Started

  • Download Haskell Language.
  • Clone the project.
  • Go in the repository.
  • Use the command "make"

Documentation

There are 3 differents documentation :

  • The Franc-C
  • The Asm created for the Franc-C
  • The Bytecodes created for the Franc-C
